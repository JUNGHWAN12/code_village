## main에 들어간 것

### 별 시스템

별 3개가 각각 조건 하나를 뜻합니다.

| 별 | 조건 | 레벨에서 정하는 값 |
|---|---|---|
| 첫째 | 클리어 | 없음 |
| 둘째 | 코드 줄 수가 목표 이하 | `par` |
| 셋째 | 로봇 명령 수가 목표 이하 | `star_steps` (없으면 정답 풀이의 명령 수) |

예외가 두 가지 있습니다.

- 계산형 레벨 5개(`바구니 세기`, `장보기 계산`, `영수증`, `똑같이 나눠 담기`, `가장 많은 채소`)는 셋째 별이
  **실행 횟수**입니다(`star_ops`). 걷는 길이 맵으로 정해져 있어 명령 수가 코드의 좋고 나쁨을 말해 주지 않기 때문입니다.
- 주사위를 쓰는 랜덤 걷기 레벨 2개(`넓은 광장`, `광장의 사과`)는 명령 별이 없습니다. 정답도 시드에 따라
  13번에서 301번까지 달라집니다. 이 레벨은 줄 수 별이 두 단계(`par + 3`, `par`)입니다.

별은 실행마다 누적됩니다. 한 번은 줄 수 별, 다른 번에 명령 별을 받아도 3개가 됩니다.

화면 표시:

- 결과창: 별마다 한 줄씩 조건과 이번 실행의 수치.
- 레벨 목록과 챕터 화면: `★☆★`처럼 어느 별인지 위치로 표시. 챕터 화면 버튼에 마우스를 올리면 조건이 나옵니다.
- 놓친 별은 마을 사람이 자기 말투로 설명합니다. 결과창에 나오고, "다시 하기"를 누르면 말풍선으로 다시 말합니다.

### 보상과 교사용 기능

- **로봇 색**: 총 별 수로 엽니다(0, 15, 30, 50, 75, 100, 전체). 챕터 화면 아래에서 고릅니다. 로봇이 한 대인
  레벨에만 적용됩니다.
- **진행 내보내기**: 챕터 화면의 버튼이 문서 폴더에 CSV를 씁니다. 레벨마다 별, 별 조건, 줄 수, 작성한 코드가
  들어갑니다. 엑셀에서 한글이 깨지지 않습니다.

### 마을 사람

- Unity 패키지의 애니메이션 클립 24개를 변환했습니다(`tools/convert_unity_anims.py`).
- 마을 사람이 대기 클립 3종(허리에 손, 뒷짐, 팔짱) 중 하나로 서 있습니다. 말하기·기쁨·슬픔 반응은 코드로
  그 위에 얹습니다.
- 말풍선이 머리뼈 대신 머리 위 고정점에 붙어, 마을 사람이 움직여도 흔들리지 않습니다.

## 남은 일

우선순위 순입니다.

1. **반 전체 집계**: 학생별 CSV 여러 개를 합쳐 학생 × 레벨 표로 보는 도구. PR #16의 이름 열이 그 준비입니다.
2. **레벨별 별 힌트**: `star_hints` 기능만 있고 내용이 비어 있습니다. 레벨마다 "여기서는 이렇게 줄인다"를
   적으면 일반 문구보다 도움이 됩니다.
3. **`star_ops` 목표 조정**: 위의 추정값을 학생 플레이를 보고 고칩니다.
4. **반응 동작 다듬기**: 기쁨·슬픔이 아직 코드로 만든 동작입니다.
5. **남은 클립 활용**: 앉기, 마시기 등 변환만 해 둔 클립.
6. **새 챕터**: 지금 15챕터 46레벨. 후보는 재귀, 정렬, 2차원 리스트, 문자열 심화.
7. **보상 확장**: 모자·장식, 챕터 완료 배지.
8. **브랜치 정리**: 머지된 원격 브랜치와 로컬 `test/all` 삭제.

## 다른 PC에서 받을 때

`asset/` 폴더는 라이선스 때문에 저장소에 없습니다. 복사해 넣은 뒤 다음을 한 번씩 실행합니다.

```
godot --headless --path . --import
python tools/convert_unity_anims.py asset/<PRO 팩>.unitypackage
```

두 번째 명령을 건너뛰어도 게임은 돌아갑니다. 마을 사람이 클립 대신 코드로 만든 자세로 섭니다.
빌드로 내보낼 때 별도 필터는 필요 없습니다. 기본 설정으로 클립이 포함됩니다.
